# Data

This folder contains project data and supporting documentation.

## Suggested structure

- `raw/` — original or minimally processed files
- `processed/` — cleaned or transformed data products
- `codebooks/` — variable definitions and supporting documentation
- `spreadsheets/` — archived spreadsheet and ZIP inputs previously stored in the root-level `RR-Raw Data/` folder; filenames and contents are preserved
- `spreadsheets/Segmentation/` — segmentation workbooks and Intone Rep audio files
- `spreadsheets/Stimulus Validation/` — stimulus validation workbook
- `spreadsheets/ReallyReallyDemographicData.xlsx` — demographic workbook

## Notes

Before sharing data publicly, confirm consent, sharing permissions, and applicable ethics requirements. Do not assume participant-level or demographic files are safe to publish merely because they are stored here. For released datasets, remove direct identifiers where appropriate, document variable coding, label files consistently, and include a dataset-specific readme or codebook.
